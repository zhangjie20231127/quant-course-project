# 量化交易技术理论与实践 · 期末研究

当前实现用于验证数据路径。`PLAN.md` 记录后续研究及提交验收。

## 复现数据试采

1. 安装 Python 依赖：`python3 -m pip install -r requirements.txt`。
2. 从课程仓库的 `ed172cf546d1e507ab4c9e35db6615149c80cedc` 版本取 `lab01_review/data/sh_stock_monthly_panel.csv`，放在 `data/course_panel.csv`。本次试采文件的 SHA-256 是 `c95550254f3091c1a987c213e0bf60ec3ac519759c1fb5c0e9cd8dc4086a1682`。
3. 执行 `python3 audit.py`。程序按年份的月末截面和市值抽样，并加入一只历史退出样本。从东方财富下载日线与估值；东财日线不可用时，用腾讯补当只股票整段价格序列，并记录来源。缓存写入 `data/cache/`，覆盖及失败记录写入 `results/`。
4. 重跑会使用缓存。试采覆盖率不代表全市场，不用于声明策略收益。

按课程历史月末状态核验整个候选池可使用 `python3 audit.py --universe panel`；也可先运行 `python3 audit.py --universe panel --batch 0 --batch-size 16` 核对第一个批次。批号从 0 开始，按排序后的股票代码分批，每批单独写出月度覆盖、逐股明细和失败清单。除信号日覆盖外，程序按基准交易日序列统计次交易日开盘价和正成交额；这两个指标仅用于检查数据，不能识别涨跌停、停牌、行情缺档等不同情形。文件缓存可供同日期范围的重跑复用。

完成取数后运行 `python3 pilot.py`，检查因子、排序、持仓、净值、Rank IC 和逐期收益归因能否串起来。产物位于 `results/pilot/`。试算使用课程面板给出的月末至次月末收益，股票池是抽样子集；不能将它作为次交易日可成交的正式回测。

课程面板最后一个信号截面是 2025-09-30，该截面的下一期收益为空。后续日线可覆盖更晚时间，扩大正式样本时还需有相应时点的股票池和状态数据。

课程仓库：<https://github.com/styluck/quant>。其中 `lab06_practice_example.py`、`lab05_practice2_example.py` 分别用于对照因子构建和横截面归因思路。

腾讯备用通道只补 OHLC，不用于补充成交额或换手率。课程面板中的 ST、是否可交易和上市天数是月度快照。东财在历史退出股票的估值可能缺失。原始数据、课程材料和本地交付件不随代码分发。
